### **软件介绍：文件分卷压缩与批量处理工具**

#### **背景与需求**
在日常工作和生活中，我们经常需要将大量文件通过微信、网盘、邮箱等平台发送给他人。然而，这些平台通常对文件大小有严格的限制（例如微信单文件不能超过100MB，邮箱附件通常限制在25MB等）。手动分卷压缩文件不仅费时费力，还容易出错。为了解决这一问题，我们开发了这款 **文件分卷压缩与批量处理工具**，帮助用户快速、高效地处理大文件和批量文件。

---

#### **核心功能**
1. **分卷压缩**  
   - 将大文件或文件夹按指定大小（例如500MB）自动分卷压缩成多个小文件。  
   - 支持自定义每个压缩包的最大大小，完美适配各种平台的文件限制。  
   - 压缩包保存在与源文件夹同级的目录中，方便查找和管理。
![image](https://github.com/user-attachments/assets/f9422916-0228-4139-be49-2ce6ca220f03)


2. **一键重命名**  
   - 批量重命名文件夹中的文件，支持自定义前缀。  
   - 文件名按顺序编号，清晰有序，方便后续整理和使用。
![image](https://github.com/user-attachments/assets/62d897c2-6d7a-4b14-bce8-0e9eae8b4148)

3. **批量解压**  
   - 一键解压多个压缩文件，每个压缩包解压到独立的文件夹中。  
   - 支持解压 `.zip` 格式文件，快速提取内容。
![image](https://github.com/user-attachments/assets/5f7d5dfb-e27d-4cb3-b959-0a2e68db9ebb)

4. **将excel文件转换为ris文件**  
   - 添加文件: 可以单独添加 Excel 文件,或者添加整个文件夹
   - 清除列表: 清空已添加的文件列表
   - 转换文件: 将列表中的 Excel 文件逐一转换为 RIS 格式,并保存在与原文件相同的目录下
![image](https://github.com/user-attachments/assets/c6019da4-b004-422e-8c2d-1c44ab460091)

---

#### **适用场景**
- **大文件分享**：将大文件分卷压缩后通过微信、邮箱、网盘等平台发送。  
- **批量文件整理**：对文件夹中的文件进行批量重命名，规范化命名格式。  
- **压缩包批量解压**：快速解压多个压缩文件，无需逐个手动解压。

---

#### **软件优势**
- **操作简单**：图形化界面，无需复杂的配置，一键完成操作。  
- **高效便捷**：自动化分卷压缩与解压，节省大量时间和精力。  
- **灵活自由**：支持自定义压缩包大小和文件名前缀，满足个性化需求。  
- **跨平台使用**：打包为 `.exe` 文件，无需安装 Python，支持 Windows 系统。

---

#### **使用方法**
1. 运行软件后，选择需要的功能（分卷压缩、一键重命名或批量解压）。  
2. 按照提示选择文件夹并输入相关参数（如压缩包大小或文件名前缀）。  
3. 等待工具自动完成任务，完成后会弹出提示框。

---

#### **使用示例**
- **分卷压缩**：  
  - 选择一个包含大文件的文件夹，设置每个压缩包的最大大小为100MB。  
  - 工具会自动将文件夹中的文件分卷压缩成多个100MB的压缩包，方便通过微信发送。

- **一键重命名**：  
  - 选择一个文件夹，输入文件名前缀（例如“照片”）。  
  - 工具会将文件夹中的文件重命名为“照片_1”、“照片_2”、“照片_3”等。

- **批量解压**：  
  - 选择一个包含多个 `.zip` 文件的文件夹。  
  - 工具会自动解压所有压缩包，并将内容保存到独立的文件夹中。
